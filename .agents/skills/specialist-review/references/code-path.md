# Code-path review

Trace user action to active route/entry point, imports, configuration, state changes and visible output. Check duplicate controllers, old routes, CSS ordering/specificity, loading/caching and fallback paths. Search hits may describe a different branch.

Deliver a short source-linked path map and the narrowest relevant test. Distinguish declared configuration from runtime values. For UI changes, inspect computed geometry and rendered behavior when possible; a changed CSS variable alone does not prove a changed image size. Escalate unclear requirements before proposing architectural rewrites.
