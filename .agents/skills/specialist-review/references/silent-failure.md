# Silent-failure review

Inspect ignored return values, empty catches, Promise.allSettled results, retries, fallbacks, fire-and-forget work and optimistic success messages. Separate persisted, queued, provider-accepted, delivered and user-visible outcomes.

Test unavailable dependency, timeout, explicit failure and partial success. Preserve saved data without duplicating sensitive actions on retry. Confirm the UI and logs reflect the actual stage reached. Never infer inbox delivery from a send-event row or call a deployment live from a successful Git merge.
