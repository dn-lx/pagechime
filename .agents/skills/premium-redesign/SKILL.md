# Premium Redesign

Use for a substantial visual/UX redesign, not isolated defects.

1. Read requirements, brand/product rules, current UI and real content/states.
2. Capture baseline desktop/mobile evidence when practical.
3. Define visual acceptance criteria: hierarchy, density, CTA priority, responsiveness, content resilience, interaction states and brand coherence.
4. Define/update the design-system contract: semantic colors, typography, spacing, radii, containers/breakpoints, elevation and motion tokens.
5. Route creative direction through `design-stack`: Taste and UI/UX Pro Max only as needed.
6. If visual approval before code reduces rework, follow `docs/FIGMA-WORKFLOW.md` and build an editable Figma specification.
7. Implement a coherent component system.
8. Use `motion-runtime` only for purposeful animation beyond CSS.
9. Use Impeccable for critique/polish against acceptance criteria.
10. Run `frontend-verification`, accessibility/visual-regression and performance-budget checks as applicable.
11. Produce a compact design-review packet.

External design packs never override requirements, brand truth, accessibility, security, performance or functional behavior.
